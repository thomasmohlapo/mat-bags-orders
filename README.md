# Maternity Bags Extraction Script

This project automates the extraction of maternity bag orders for GEMS and SAMWUMED medical schemes. It connects to a MySQL database, runs SQL queries, saves the results to Excel files, and sends email notifications based on the day of the week and data availability.

## ⚙️ Setup Instructions

1. **Clone the repository** (if applicable) or place the script in your working directory.

2. **Create and activate a virtual environment**:
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows use: venv\\Scripts\\activate
   ```

3. **Install dependencies**:
    ```pip install -r requirements.txt```

4. **Create a .env file** in the root directory and add the correct environment variables:
```
DB_HOST=your_database_host
DB_USER=your_database_user
DB_PASSWORD=your_database_password
DB_NAME1=your_database_name_for_order_date
DB_NAME2=your_database_name_for_extraction
SMTP_USER=your_email_address
SMTP_RECEIVER=receiver_email_address
SMTP_SERVER=smtp.yourserver.com
```

5. **Create the following folders** in the root directory:

 - Gems Bags
 - Samwumed Bags

These folders will store the Excel files generated by the script.


## 🕒 Script Behavior

Monday to Friday: Extracts GEMS orders.
Thursday only: Extracts both GEMS and SAMWUMED orders.
Monday: Checks if data was loaded on Friday.
Other days: Checks if data was loaded the previous day.

## ✉️ Email Notifications
The script sends an email to notify whether the data was loaded successfully the previous day. If not, it alerts the user to check the database.
## 📝 Logging
All operations and errors are logged to a file named bags.log.
